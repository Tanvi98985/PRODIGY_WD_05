# 🌦️ Weatherly - AI Powered Weather App

A modern futuristic weather application built using HTML, CSS, and JavaScript with WeatherAPI integration and AI-powered weather assistant features.

---

## ✨ Features

- 🌍 Real-time weather search
- 🌡️ Current temperature & weather conditions
- 💨 Wind speed, humidity, visibility & pressure
- 🌙 Dark / Light mode toggle
- 🎨 Modern glassmorphism UI
- 📱 Fully responsive design
- ⚡ Smooth animations & transitions
- 🤖 Weather Assistant insights
- 🌈 Dynamic weather-based backgrounds
- 🔍 Smart city search
- 📲 Mobile-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- WeatherAPI
- Gemini API (for AI weather insights)
